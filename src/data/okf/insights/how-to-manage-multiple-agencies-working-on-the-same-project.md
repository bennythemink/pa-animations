# Summary
Running multiple agencies on one project isn't inherently risky, problems arise when nobody has clearly defined who owns what. A joint kickoff should set out responsibilities, expected deliverables and formats, handover timelines, and an escalation process, ideally chaired by the client or a designated lead agency. Watch for agencies operating outside their core competency (e.g. a branding team designing app UI), since those gaps often only surface once development starts, and bring in independent consulting early if unsure how to structure it.
