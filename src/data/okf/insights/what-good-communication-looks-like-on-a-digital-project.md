# Summary
Good communication on a digital project isn't about constant availability, it's about documentation and visibility, starting with clear scoping before any design or development begins. Once work is underway it looks like defined stage gates, a regular update cadence, progress tracked against the agreed timeline (not just activity lists), risks flagged early with a mitigation plan, and visible weekly progress. If an agency isn't providing this, ask for it directly, a good one will already have a process for it.
