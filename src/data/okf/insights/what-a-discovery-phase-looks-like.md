# Summary
A Discovery phase typically centres on a 2-3 hour workshop with around six key stakeholders, sometimes followed by smaller deep-dive sessions. The output should be a report covering a summary of findings, requirements as user stories and acceptance criteria, timelines, and an itemised quote, detailed enough that any competent team could pick it up. Clients should aim to own these deliverables so they retain full control if they switch vendors.
