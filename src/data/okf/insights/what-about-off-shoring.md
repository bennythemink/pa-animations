# Summary
Off-shoring isn't inherently risky, but it works best when the client has strong project management, clear requirements, and cultural/timezone awareness in-house. Success depends on tactics like writing requirements as user stories with acceptance criteria, keeping regular access to the source code, having technical documentation independently reviewed, and doing design locally while building off-shore. Without those capabilities in-house, get independent help managing the risk rather than avoiding off-shoring altogether.
